# Java Learning Notes

This repository is a structured collection of Java learning resources covering core language fundamentals, object-oriented programming, concurrency, memory management, build tools, database access, testing, logging, cryptography, and modern Java features.

It is designed as a personal Java knowledge base and quick revision hub for interview preparation, backend development, and long-term concept review.

## Repository Highlights

- 46 PDF notes covering Java fundamentals and advanced topics
- 31 organized topic folders
- Supporting screenshots and one text/code example
- Coverage from beginner concepts to production-oriented tools and frameworks
- Useful for revision, interview preparation, and structured self-study

## Suggested Study Path

1. Start with **Variables, Data Types, Type Casting**, then move to **OOPs**.
2. Review **Static & Final**, **Static vs Dynamic Binding**, **Nested Classes**, and **Initializer Block**.
3. Continue with **Exception Handling**, **IO Operations**, **Regex**, and **Networking Socket**.
4. Learn Java collections and language features through **Iterator**, **Deque**, **Generics**, **Record**, and **Annotations**.
5. Study functional Java using **Lambda Function**, **Functional Composition**, and **Higher-Order Functions**.
6. Build advanced understanding with **Threads**, **Threads & Concurrency**, **Volatile Keyword**, and **Memory Management**.
7. Explore real-world backend development topics like **Build Tools**, **Database Access**, **Logging Frameworks**, **Testing**, and **Cryptography**.
